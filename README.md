# Personal Space

Portfolio: index.html
Projects: project.html
Coursework: WeeklyAssignment/W3 through WeeklyAssignment/W7

Run locally with `node server.js`, then open http://localhost:3000.
Upload the website folder to a static host to obtain a public URL.
